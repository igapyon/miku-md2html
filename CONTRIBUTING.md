# Contributing

Use Node.js 22 or newer. Install dependencies with `npm install`, then run `npm test` and `npm run smoke:all` for changes to the core or bundles.

Keep Markdown, HTML policy, image validation, SVG policy, and output sizing in the product core. Keep filesystem resolution and output commits in Node adapters. Update API/CLI documentation and the relevant tests when a public behavior changes.

Do not commit `node_modules/`, generated `dist/` or `bundle/` artifacts, local work under `workplace/`, or project-local copies of shared skills. Preserve unrelated existing changes. Do not push, publish, create a release, or upload release assets as part of local development.
